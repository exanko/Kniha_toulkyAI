# 08 · Firma v Gitu / A company in Git – scénář

**Stav:** ✅ hotovo – viz [README dílu](README.md)

Do ElevenLabs vložit jen text z bloku – scény jsou oddělené prázdným řádkem.

## 🇨🇿 Česky

```
Jak dostat malou firmu do doby AI?

Založ jedno místo pro všechno. Repozitář v Gitu. Jeden zdroj pravdy.

Nahraj do něj data a nech agenta, ať se v nich zorientuje. Zeptej se ho, jestli je mu všechno jasné a kde vidí rozpory.

Pak stavějte od základů nahoru. Výpočty, smlouvy, produkty, příběh firmy.

Celou dobu mu dodávej svoje know-how. A ptej se ho, co si o tom kriticky myslí.

Git hlídá každou změnu. Nic se neztratí a vždycky se dá vrátit zpět.

Pak stačí zadat konkrétního zákazníka a agent připraví prezentaci, leták nebo kalkulačku přímo pro něj.

Jen pozor: pro velkou firmu s mnoha lidmi už to nestačí. Tam je potřeba robustnější systém.
```

## 🇬🇧 English

```
How do you bring a small business into the age of AI?

Create one place for everything. A Git repository. A single source of truth.

Put your data in and let the agent get its bearings. Ask it whether everything is clear, and where it sees contradictions.

Then build from the ground up. Calculations, contracts, products, your company's story.

Keep feeding it your know-how. And ask it what it honestly thinks.

Git tracks every change. Nothing gets lost, and you can always go back.

Then just name a specific customer, and the agent prepares a presentation, a flyer or a calculator made just for them.

Just one catch: for a big company with many people, this isn't enough. That needs a more robust system.
```

## Obraz (návrh)

1. otázka · 2. jedna složka / repozitář uprostřed · 3. soubory padají do repa, agent se ptá „Jasné? Rozpory?“ · 4. pyramida od základů nahoru · 5. dialog člověk ↔ agent · 6. časová osa commitů s tlačítkem zpět · 7. ze zákazníka se rozvětví prezentace, leták, kalkulačka · 8. malá firma ✓ vs. velká firma → robustní systém

Pozn.: workflow je podle knihy (kapitola Workflow) a uzavírá ho výhrada z kapitoly „Když projekt vyroste“.
