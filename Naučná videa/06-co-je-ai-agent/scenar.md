# 06 · Co je AI agent / What is an AI agent – scénář

**Stav:** ✅ hotovo – viz [README dílu](README.md)

Do ElevenLabs vložit jen text z bloku – scény jsou oddělené prázdným řádkem.

## 🇨🇿 Česky

```
Co je vlastně AI agent?

Samotný jazykový model je jen mozek. Chytrý, ale nemá ruce ani paměť.

Agent mu dá nástroje. Může hledat na webu, psát soubory, spouštět programy.

Dá mu paměť. Důležité věci si zapíše a příště je ví.

A když se mu něco povede, uloží si postup. Říká se tomu skill.

Agent pak sám zkouší, kontroluje a opravuje, dokud nesplní cíl.

Jen pozor: jde přesně tam, kam ho nasměruješ. Tak ho nasměruj dobře.
```

## 🇬🇧 English

```
What actually is an AI agent?

A language model on its own is just a brain. Smart, but no hands and no memory.

An agent gives it tools. It can search the web, write files, run programs.

It gives it memory. It writes down what matters and remembers it next time.

And when something works, it saves the recipe. That's called a skill.

Then the agent tries, checks and fixes things on its own, until the goal is done.

Just be careful: it goes exactly where you point it. So point it well.
```

## Obraz (návrh)

1. otázka · 2. mozek bez rukou a paměti · 3. mozek + ikony nástrojů (web, soubor, terminál) · 4. zápisník paměti · 5. uložený „recept“ = skill · 6. smyčka zkus → zkontroluj → oprav → cíl ✓ · 7. šipka/kompas k cíli

Pozn.: „zadání je pro něj svaté“ z knihy je zmírněno na „jde přesně tam, kam ho nasměruješ“ (recenzenti tvrzení označili za příliš kategorické).
