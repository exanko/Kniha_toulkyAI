# Toulky AI

### Moje cesta s umělou inteligencí

Autor **Petr Rubeš** sepisuje svůj osobní technologický memoár o setkání s umělou inteligencí – od prvního „kecala“ v okně prohlížeče přes lokální grafické karty a agenty až po tým, který nikdy neměl. Umělá inteligence mu knihu pak i hodnotí a diskutuje o ní s ním: recenze, rozbor toho, co je v textu pravda a co nadsázka, i follow-up rozhovory autora s AI kritiky jsou součástí knihy.
